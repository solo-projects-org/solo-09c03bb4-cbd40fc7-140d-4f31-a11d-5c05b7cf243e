# 灌装线欠重累计复检

灌装线每次少装几克，连续下来就要复检。系统把每条称重统一换算成整数**净重**，按序号顺序把
**(499 − 净重)** 计入累计，累计 **< 0 归零**；累计 **≥ 20 克** 时记录一条复检事件
（本轮累计转正起点序号 → 触发序号、累计克数），随后清零。

## 运行

```bash
docker compose up --build        # 打开 http://localhost:5000
```

数据保存在名为 `filling-data` 的卷里（容器内 `/data/filling.db`），重启、失败后不丢。
不用 Docker 也可以本地跑：

```bash
pip install -r requirements.txt
python app.py                    # 默认 ./filling.db，可用 FILLING_DB 指定
```

## 两种称重 CSV（首行表头均可省，克重均为整数）

1. **两列「抽检序号,克重」**：旧秤/旧库口径，克重按**直接净重**处理（来源 `direct`）；
2. **三列「抽检序号,毛重,包装批号」**：新秤只导出毛重，按包装批登记的皮重扣除，
   **净重 = 毛重 − 皮重**（来源 `gross`，保存毛重、包装批号与所用皮重）。

一个文件只能是同一种格式（按首个数据行的列数分派，行列数不一致整批拒绝）。

- **同号可更正**：已存在的序号再次上传即覆盖并触发复算；
- **同号以最后一次成功上传的来源为准**：即使净重相同，直接净重与毛重扣皮互切也属更正，
  来源行（毛重、包装批号、皮重）一并替换；同号且净重、来源完全一致才算无改动；
- **新号只往后追加**：新序号必须大于当前最大序号，否则整批拒绝；
- 文件内序号不得重复；序号 ≥ 1，净重/毛重/皮重均为非负整数；
- **缺皮重或负净重整次退回**：三列 CSV 引用未登记的包装批，或毛重 − 皮重为负，
  整批不生效，原状态不变。

## 包装批皮重登记与更正

网页「包装批皮重登记 / 更正」表单（或 `POST /api/tare`）上传两列
**「包装批号,皮重」**，可一次多行：

- 新批号即登记；已存在且皮重不同即更正；皮重未变不做换算；
- 皮重更正时**只重新换算仍引用该包装批的毛重称重**（直接净重与其他包装批的称重不动），
  净重、累计与复检清单随之复算；
- 任一引用称重算出负净重，**整次操作退回**（已写入的皮重也回滚）。

## 网页查询

- 首页「按序号查净重与来源」（`GET /weighing?seq=`、`GET /api/weighing/<序号>`）：
  返回净重、来源（直接净重 / 毛重扣皮），毛重记录另列毛重、包装批号与所用皮重；
- 「毛重换算记录」表逐条列出 **毛重、包装批号、所用皮重、净重**。

## 复算策略（增量）

每次上传一个事务，皮重、称重来源、净重与复检清单一同提交：

1. **跳过首处改动前的称重**：从首个改动序号起算，改动前的累计值/本轮起点直接取
   `run_state` 中保存的状态；
2. **汇合即沿用**：复算途中若已越过全部更正、当前序号仍是旧数据，且（累计值，本轮起点）
   与旧结果一致，则之后的旧状态与旧复检事件原样保留，不再重读重量；
3. 若旧末尾之后还有本次新增的序号，则从旧末尾状态继续处理新增部分。

每批次的类型（净重上传/毛重上传/皮重登记）、复算起点（`first_changed`）与沿用点
（`resumed_at`）记录在 `batches` 表，网页「批次记录」可见。

## 并发与持久化

- 进程内全局锁 + `BEGIN IMMEDIATE` 写事务：并发上传/皮重操作按生效顺序串行处理；
- 每次操作要么整体生效要么整体回滚，失败不影响最近一次成功结果；
- SQLite（WAL）落盘，重启后最近一次成功结果仍可查；
- 旧版数据库（`weighings` 仅有 `weight` 列）启动时自动迁移为直接净重口径，
  历史称重、累计状态与批次记录保留，迁移幂等。

## 接口

| 方法/路径 | 说明 |
| --- | --- |
| `GET /` | 网页：累计、复检清单、最近称重、换算记录、包装批、批次记录、上传表单 |
| `GET /weighing?seq=` | 网页按序号查净重与来源 |
| `POST /upload` | 表单上传两列或三列称重 CSV（文件或粘贴文本） |
| `POST /tare` | 表单上传「包装批号,皮重」CSV |
| `POST /api/upload` | 称重 CSV 正文（按列数自动分派），返回 JSON（成功 200 / 数据问题 400） |
| `POST /api/tare` | 皮重 CSV 正文，返回 JSON（含重新换算的序号 `affected_seqs`） |
| `GET /api/weighing/<序号>` | 单条称重：净重、来源、毛重、包装批号、所用皮重 |
| `GET /api/state` | 当前累计、本轮起点、最近序号、计数 |
| `GET /api/events` | 复检清单（按触发序号排序） |
| `GET /api/weighings?limit=` | 称重记录（含来源与毛重字段） |
| `GET /api/packaging-batches` | 已登记包装批与皮重 |
| `GET /healthz` | 健康检查 |
